<Card title="Keyframe SDK" href="https://www.npmjs.com/package/@keyframelabs/sdk">
  The universal, low-level SDK. You implement the UI, state management, and agent/llm binding yourself. Drives an avatar from any stack that can stream audio — including agent platforms Keyframe doesn't natively support.
</Card>

<Card title="Keyframe Elements" href="https://www.npmjs.com/package/@keyframelabs/elements">
  Primitives that work with or without a UI framework. Headless classes for building your own UI — `PersonaEmbed` for hosted pipelines, `PersonaView` for self managed — plus the drop-in `<kfl-embed>` widget that powers the Widget path. We handle state and the agent/llm binding for natively supported platforms (ElevenLabs Agents, OpenAI Realtime, Keyframe Voice Agent).
</Card>

<Card title="Keyframe React" href="https://www.npmjs.com/package/@keyframelabs/react">
  React bindings for `@keyframelabs/elements` plus ready-made UI components (customizable). We handle the UI, state, and agent/llm binding. Supports hosted pipelines (publishable key) today.
</Card>
