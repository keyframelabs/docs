<Info>
  To use an avatar in an API call, set the `persona_id` or `persona_slug` field to the listed ID or slug.
</Info>

<Tip>
  Browse all available avatars and try them live in the [Keyframe platform dashboard](https://platform.keyframelabs.com/persona-library).
</Tip>

## persona-1.5-live

<Info>
  The `persona-1.5-live` model is our first that is capable of expressing emotion (anger, happiness and sadness).
</Info>
